# design

Design-phase skills for TALXIS / Power Platform projects — the artifacts a team
produces before implementation starts. One skill so far:

| Skill | Use when… |
|---|---|
| `acceptance-tests` | turning a user story's acceptance criteria into executable Gherkin `.feature` files in the project's companion tests repo |

Planned next: screen prototypes, backlog decomposition, and technical
specifications. Feature-file and tests-repo conventions live in
[TALXIS/docs-patterns-practices](https://github.com/TALXIS/docs-patterns-practices);
the step-binding catalog lives in
[TALXIS/tools-testkit-ui](https://github.com/TALXIS/tools-testkit-ui).

## Install

```
/plugin marketplace add TALXIS/skills
/plugin install design@talxis
```
